Review Deck links

Pull request links you open from outside Azure DevOps (chat, email, another site) open in the Deck. Links inside Azure DevOps, and the Deck's own "open in Azure DevOps" link, still open the classic page.

There's nothing to paste: the first time you open Repos → Deck in an organization, its Deck is added here, for all of its projects. You can still paste or remove a Deck page's address.
